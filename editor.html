Los datos se insertan por secciones. Un sección empieza por [nombre sección] y se exitende hasta que empiece otra sección. 

[Seccion 1]
linea 1
linea 2
[Seccion 2]
linea 1
linea 2
linea 3

Hay una sección para la fecha ([Fecha]), y contiene la fecha en forma {año} / {mes} / { día o días }. El formato de los días es libre, puede ser un único día o varios días separados por guión. 

[Fecha]
2025 / 09 / 20-21

Las demás secciones corresponden cada una a una categoría. Cada línea corresponde a su vez a un partido. Los datos de un partido son separados por ; (punto y coma). Tenemos por orden los siguientes campos:

  1. Neskak o Mutilak
  2. La fecha y la hora en formato libre
  3. El lugar del encuentro. Si el lugar contiene 'Alluralde', aparecera de otro color
  4. El equipo local
  5. El equipo visitante
  6. Los goles del equipo local (opcional)
  7. Los goles del equipo visitante (opcional)
[SENIOR]
Neskak ; 17 MAI 18:00 ; Egia (Donosita) ; Egia Baztarre Taberna ; Leizaran Lanbroa Taberna ; 28 ; 31
Mutilak ; 17 MAI 18:99 ; Ispilla (Zumarraga) ; Urola E.K. Crist. Goiherro ; Leizaran Eskubalioa

Los datos de goles (opcionales) servirán para la platilla de resultados.
